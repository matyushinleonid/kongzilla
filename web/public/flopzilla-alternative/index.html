A free Flopzilla alternative that runs in your browser

Kongzilla is an open-source clone of the analysis loop Flopzilla made standard: enter a range, enter a flop, read what the range actually hits, then filter it down to the hands that would keep going. No install, no account, no licence key, and nothing leaves your machine.

Open Kongzilla

What it does

  • Range matrix. 169 cells, paint with weights, text notation both ways (AKs+, 77-99, QJo), a percentage slider over a real hand ranking, and combo level suit selection.
  • Board statistics. The full ladder — straight flush down to no made hand, plus flushdraws, open-enders, gutshots, backdoors and the combination rows — recomputed as you type.
  • Filters. Mark which classes continue and the whole panel re-reads through them, or cut the range to its strongest share by equity, which keeps the draws a class ladder would fold.
  • Equity. Exact enumeration, range versus range or hand versus range, with a per-combo equity matrix and a distribution graph.
  • Flop statistics. How a range performs averaged over all 22,100 flops, and how often each kind of flop comes up.
  • Preflop charts. Solver ranges for 20–100bb tournament play, by seat and by spot.

Frequently asked

Is it really free?

Yes. It is MIT licensed and the whole engine is on GitHub. There is no paid tier and no account.

Does it work on a Mac?

Yes. Flopzilla is a Windows program; Kongzilla is a web page, so macOS, Linux, ChromeOS and tablets all work the same.

Can I use it offline?

Yes. Every release ships a single HTML file with the engine inside it — download it once, double-click it, and it runs with no network at all.

Is my range data sent anywhere?

No. The analysis engine is compiled to WebAssembly and runs inside your browser tab. There is no server to send anything to.
