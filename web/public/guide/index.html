Using Kongzilla

Everything recomputes as you go, so there is no calculate button anywhere. Five minutes end to end.

1. Build a range

Drag across the matrix to paint, or type notation into the box under it — AKs+, 77-99, QJo, and KQs:0.5 for a hand played half the time. The slider under the matrix takes a band off the top of a hand ranking, and the All / Pocket / Broadway / Suited buttons add whole groups. Shift-click a cell to pick individual suit combinations.

The chart chips below load solver ranges for tournament play: pick a stack depth, then a seat. The chip stays lit while the range is still that chart.

2. Deal a flop

Click three cards in the board grid, or press Random. Every row in the flops panel also deals — a random two-tone flop, a random ace-high flop — which is faster than thinking one up.

3. Read the statistics

The middle panel is the ladder: made hands, then draws, then the combinations that matter (flushdraw plus pair, and so on). Hover a row and the matrix lights up with the cells that hold it, and every other row re-reads as "how often, given this one".

Switch between absolute ("exactly this") and cumulative ("this or better") with the button in the header, and between percentages and combination counts with Tab.

4. Narrow it down

Mark which classes continue and which are gone, then turn the filters on: the whole panel, the equity and the effective range all re-read through them.

Or use Continue top, which cuts the range to its strongest share by equity on this board. Unlike a class ladder it keeps the draws — a nut flushdraw with no pair outranks a middle pair, which is how it is actually played — and it freezes the combinations it chose, so they carry to the turn and river.

5. Read equity

Fill the second seat for range versus range. For hand versus range, put the one hand in a seat — a hand is a range with one combination in it, and everything that works for a range works for it. Add a third seat with + for a multiway pot, and choose which range the equity views measure against from the output panel's header. The output panel has the equity matrix (every combination, coloured), the equity graph (the distribution, strongest first, with the opponent drawn alongside) and hotness (what each remaining card does to the matchup).

The keyboard

Press ? for the full list. The ones worth learning first: R deals a random flop, Tab swaps percentages for combination counts, the arrow keys step through the streets, 1 2 3 apply the flop, turn and river filters, and Alt+S clears everything. Anyone arriving from Flopzilla will find its own keys where they expect them, except the few a browser refuses to hand over — the list says which moved.

Sharing and saving

Copy link packs the whole session into the URL. Save writes a file you can load back. Nothing is sent anywhere; the engine runs inside your browser tab.
